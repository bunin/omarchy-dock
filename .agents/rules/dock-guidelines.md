# Правила и дизайн-система Omarchy Dock

1. **Индикаторы запуска (`runningDot`)**:
   - Всегда располагаются горизонтальной чёрточкой строго под иконкой по центру (`anchors.bottom: parent.bottom`, `anchors.bottomMargin: 2`, `anchors.horizontalCenter: parent.horizontalCenter`) — как для горизонтального, так и для вертикального дока.

2. **Оптическое выравнивание символов (`OpticalGlyph`)**:
   - Для всех Nerd Font и Unicode глифов в папках и бейджах всегда использовать `OpticalGlyph` из `qs.Ui`, чтобы компенсировать асимметричные боковые отступы шрифтов.

3. **Режим покачивания и редактирования**:
   - Активация: зажатие ЛКМ 450ms с установкой флага `didLongPress = true` (предотвращает ложный клик при отпускании).
   - Масштаб иконки: `0.82`.
   - Анимация: $\pm 3.8^\circ$, `105ms`, `Easing.InOutSine`.
   - Бейджи: над иконкой (`bottomMargin: -5`). Звезда всегда цельная `★`.
   - При перетаскивании: бейджи и курсор мыши полностью скрываются (`Qt.BlankCursor`).
   - Выход: `Esc` или ПКМ.

4. **Сквозная навигация по папкам**:
   - Клик по папке в режиме редактирования открывает её сразу в режиме редактирования.
   - Переключение между папками бесшовное (прошлая закрывается, новая открывается в редактировании).
   - Зажатие внутри папки активирует редактирование и в папке, и на доке.
   - Перетаскивание на открытую папку не закрывает её.

5. **Настройки виджета (`~/.config/omarchy/dock-settings.json`)**:
   - `autohide`: автоскрытие дока.
   - `showFolderTitles`: переключатель отображения названий папок.

6. **Безопасность Git**:
   - Запрещено выполнять `git push` без прямого разрешения.
